# WatchMouse：手机键盘和鼠标

在 Windows 上打开 **WatchMouse.exe**，接收器和手机网页会一起启动。手机连接同一个 Wi-Fi，扫描应用里的二维码，即可控制电脑。链接中已经包含配对密钥，无需手动填写 IP 或额外开启网页服务器。

## 日常使用

1. 双击 `dist\WatchMouse.exe`（开发时也可以双击 `run.bat`）。
2. 手机连接家里的 Wi-Fi，扫描二维码，或者打开应用中复制的链接。
3. 在电脑上选中要操作的窗口，再使用手机上的触控板、点击、滚轮和键盘。
4. 底部有三个模式：抖音模式只显示大号上箭头、播放暂停、下箭头；鼠标模式显示触控板；键鼠模式显示触控板和手机输入区。会记住上次选择，输入使用手机自己的键盘。界面顶部没有标题，说明文字和操作成功提示均不常驻显示。
5. 键鼠模式中输入或粘贴文字后点发送图标。删除按钮有手机草稿时删草稿（选区或光标左侧的一个完整字符）；草稿为空时向电脑发送退格。Delete 本身只删光标右侧文字，光标在末尾时不会变化。常用控件使用图标并保留无障碍名称。
6. 语音输入使用三星手机输入法自带的麦克风。接收器通过局域网 HTTP 提供网页，手机输入法的语音转文字不依赖网页麦克风接口。
7. 鼠标模式将触控板、左右键、拖动整合在一起，右侧滚动带支持单指上下滑动，也可点两端箭头。键鼠竖屏时输入区在触控板下方，横屏时在右侧；手机键盘弹出后，触控板随可用空间缩小。鼠标速度移到底部连接设置。
8. 横屏时网页会自动调整布局。关闭桌面应用会停止它启动的接收器；重新打开会自动恢复。

配对链接只分享给自己的设备。应用默认使用 `53514` 端口；无需连接之前位于其他电脑的 `8000` 网页服务。

底部小圆点是连接入口：绿点表示正常、红点表示未连接，点它可展开配对设置。正常使用时界面没有连接状态文字。

## 手机作为电脑麦克风：本次检查

当前 LAN HTTP 页面实际检测为 `isSecureContext=false`、`navigator.mediaDevices=undefined`，浏览器没有开放录音接口；这是浏览器的安全上下文限制，见 [getUserMedia 文档](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)。电脑存在 ToDesk 虚拟音频设备，但它用于 ToDesk 自己的远程麦克风映射，没有确认能作为本项目的通用音频输入桥接，见 [ToDesk 说明](https://www.todesk.com/helpcenter/solo-376.html)。因此暂未实现手机原声作为 Windows 系统麦克风，未安装音频驱动或修改音频设备设置；已有语音转文字发送不受影响。

## Windows 防火墙和连接

在自己的家庭网络中，将 Windows 的 Wi-Fi 网络类型设置为“专用网络”。首次打开 Windows 防火墙提示时允许专用网络访问。

如果手机无法连接，点击桌面应用中的“允许局域网连接”。Windows 会请求管理员授权，授权只用于添加这个程序、这个 TCP 端口、专用网络、同一子网的入站规则。普通使用无需管理员权限。如果应用本身已经以管理员权限运行，启动时会自动配置这条规则。

应用里可以刷新网络地址；如果电脑同时连接有线网络和 Wi-Fi，也可以从地址列表选择手机所在网络的地址。只有 `127.0.0.1` 时，先连接网络再刷新。若出现“端口已被占用”，先关闭之前启动的接收器或占用该端口的软件，再点击“启动服务”。应用不会终止其他程序。

本机设置和配对密钥保存在 `%LOCALAPPDATA%\WatchMouse\config.json`，启动日志位于同一目录的 `desktop.log`。重复双击应用会显示已经运行的窗口。

## 从源码运行

安装 Python 3.10 或更新版本，在这个目录打开 PowerShell：

```powershell
py -3 -m pip install -r requirements-build.txt
py -3 app.py
```

`run.bat` 优先打开已打包的 EXE；没有 EXE 时，会优先使用构建环境中的 Python，最后使用系统的 Python。接收器也可以单独运行：

```powershell
py -3 receiver.py
```

## 构建独立 EXE

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

构建脚本在项目内创建 `.build-venv`，安装 PyInstaller 和二维码组件，再打包应用、Python 运行时和网页资源。输出为 `dist\WatchMouse.exe`。将这个 EXE 复制到另一台 Windows 电脑后即可运行，无需再安装 Python，也无需另外复制网页文件。

依赖已经安装时，可用 `build.ps1 -SkipInstall` 再次打包。资源更新后必须重新构建 EXE。打包时请先关闭旧的 `WatchMouse.exe`，避免 Windows 锁定输出文件。

## 手机和手表

手机直接使用浏览器；也可以通过浏览器菜单添加到主屏幕，形成独立入口。完整的 Android APK 是另一个打包方向。

已经提供 `/watch` 入口：用配对链接打开主页后选择手表简版，或者将链接路径改为 `/watch`，保留 `?token=...`。手表控制使用普通链接，不依赖 JavaScript；可以按方向移动光标、左键/右键点击、滚动、暂停、发送回车/退格。每个操作链接只执行一次，刷新或重复请求不会再触发；页面需在五分钟内点击，否则刷新后重试。文字发送使用普通表单，取决于手表浏览器的表单支持。基础链接控制通过浏览器与 HTTP 测试；尚未在真实 Apple Watch 上测试局域网访问和使用体验。
